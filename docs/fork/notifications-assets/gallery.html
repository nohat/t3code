Review mockups for the notifications proposal. Screen IDs N01 to N33 are the UX specification's.

All screens are proposals with fabricated data; nothing here is implemented or verified. Colors approximate the app's existing roles and are not exact. The warm brutalism preview uses the optional Ledger profile (4 px radii) and is not part of the default look. Gallery controls work; every other control only announces that it is illustrative. The gallery has no animation. OS-owned surfaces draw only the content area the app controls.

Toasts are the foreground surface. Persistent (approval, input) and auto-hiding (failed, completed) toasts differ by an outlined icon tile and a stronger border, not by animation.

Each state shows the system's truth with numbered steps and a re-check; the saved choice is never rewritten. State glyphs are neutral (bell, bell-off) and the blocked notice is a quiet status toast, not an error: toasts, Needs me, and badges still work. Button labels (Allow notifications, Check again, Open System Settings, Open Settings) come from the copy deck.
